# Project Context

## What this repository does

This repository contains a browser-based Memory / Concentration card game. Players flip cards to find matching pairs, complete the board, and try to finish with as few moves and as little time as possible.

The app is implemented as a single-page web application using plain HTML, CSS, and JavaScript. It includes responsive game layouts, accessibility support, score tracking, and local persistence for high scores.

## Core features

- 4x4 and 6x6 grid modes
- Card flip animations
- Move counter
- Timer
- Star rating based on performance
- Best scores saved in browser localStorage
- Keyboard-accessible controls
- Responsive layout for desktop and mobile
- No external dependencies or libraries

## How it is structured

- `memory-game.html` contains the complete app: markup, styling, and game logic in one file
- `README.md` provides setup and usage information

## How to run it

Open `memory-game.html` directly in a browser, or serve the project locally with a simple HTTP server such as:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/memory-game.html
```
